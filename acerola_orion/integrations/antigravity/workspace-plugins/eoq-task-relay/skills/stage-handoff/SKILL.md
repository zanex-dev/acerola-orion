# Stage Handoff（≤1.5K 阶段交接单协议）

1. **严控体积（≤ 2,400 字符）**：只写结论、文件行号锚点与下一步指令，禁贴整段源码或长日志。
2. **仅热窗撰写**：冷窗（>250s 且 >30K）直接用 Hook 生成的 `cold_rescue_*.md` 或 `session-recall` 切片，勿空唤模型。
3. **非破坏性落盘**：写入 `<workspace>/.agents/checkpoints/handoff_<YYYYMMDD_HHMM>_<slug>.md`（无工程目录时写入当前 Artifact 目录），禁覆盖旧单。
4. **落盘即停**：给出交接单 `file:///` 链接与复制用启动指令（≤10 行回复，若由 `175K+` 触发附注双倍计价预警），**立即结束回合**。

## 标准模板（顶栏元数据与 `## 4.` 引用行为看板机读锚点，勿改格式）

```markdown
# 阶段交接单：<主题>
- 来源会话：`<conversationId 前8位>` | 落盘时间：`YYYY-MM-DD HH:MM` | 收口水位：`~XXK`
- 关联工作区：`<workspace path>`

## 1. 任务目标与当前阶段
- **总目标**：<1 句话>
- **本段已完成**：<2~4 条已验证成果及验证方式>
- **下一窗唯一目标**：<明确单阶段边界>

## 2. 已验证事实与关键文件锚点
- `<路径>#L起-L止`：<核心逻辑 / 已改摘要>（仅列下一窗必读的 3~8 个锚点）

## 3. 硬约束、踩坑与未决项
- **已排除方案 / 踩坑**：<防重复试错>
- **未决项**：<无则写“无”>

## 4. 新窗口首条启动指令（可直接复制）
> 请先读取交接单 `<交接单绝对路径>`，严格承接其中第 1~3 节的结论与锚点，直接开始执行「下一窗唯一目标」：<1 句话精准指令>。
```
