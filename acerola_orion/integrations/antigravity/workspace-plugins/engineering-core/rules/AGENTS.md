# 代码工程核心准则（仅工程工作区生效）

## 1. 先读完拆卡、再轻载施工（200K 上下文防爆铁律）
- **第一步永远是只读侦查 + 拆卡**：凡涉及**新建功能、重构、修 Bug、跨文件改动或任何需先看代码才能动笔**的工程任务，默认强制先激活 `task-decomposer` 模式 A：在当前窗**只读不写业务源码**，一次性读透相关上下文、确诊根因/列全影响面，落盘 `PLAN.md` 与 `T01~Tn` 原子卡片至 `.agents/tasks/`，并用大白话输出「这是做什么的 + 怎么启动 + 执行完之后你该做什么」导航后**立即停手**，严禁边读边改。
- **执行窗只认卡片、禁盲搜**：持卡进入施工（模式 B）时，**不读 `PLAN.md` 背景**，仅读目标 `T0x` 卡与直接前置回执，严格按卡内白名单行段定点读写；严禁全仓 `grep`、扫目录或整文件通读。若确需越界补读超过 2 次，**立刻熔断停手**并输出《缺料单》退回探索窗；验收打勾后须用大白话报告「刚做完了什么 + 接下来你该做什么（含解锁卡或终卡验收提示）」再单步停顿。
- **唯一豁免口**：仅当任务为**零探索单点微改**（用户已指明唯一文件与改法，无需翻查其他源码）、纯问答讨论、或用户显式要求“直接改，别拆卡”时，方可免拆卡直接动笔。

## 2. 查证与验证铁律
- **先查证再断言**：禁凭记忆盲猜本地源码、函数签名、配置或新版库接口；动笔前须直读源码或查最新文档（优先 `context7` / 官方源）。
- **无验证不交差**：宣称修复或配置完成前，须实跑构建、语法检查、测试或状态核验确认通过；受环境限制无法验证处须明示。

## 3. 手术刀极简编码（Karpathy Minimalism）
- **最小改动**：严格聚焦当前需求，禁顺手重构/格式化无关代码，完整保留无关注释与公共接口兼容。
- **确认与留底**：仅对**高危/不可逆变更**（删数据、强推远端、破坏性覆盖）或需求矛盾前置确认；开启 `/plan` 按阶段停顿，自主/子智能体模式一气跑到底。整文件重写或大改前须留副本至 `_versions/`。
- **冷库外迁联动**：完成新版本创建、发版打包、跨版重构或任务包结项后，激活 `version-seal` 技能先跑 `python -m acerola_orion archive scan --json` 扫描旧版，经用户确认迭代（或符合 `auto_after_settle` 策略）后调用 `archive seal --confirm` 校验外迁至 `~/.gemini/acerola_orion/version_vault/` 外部不可删冷库，严禁直接删除旧版；如需云端同步，提示执行 `python -m acerola_orion archive push`（或可选桌面穿透示例 `[推送冷库](agyrun://orion-archive-push?silent)`）。

## 4. Windows 隔离桌面与可选桌面穿透示例（`agyrun://`）
- `run_command` 位于隐藏桌面（`WinSta0\exebox-*`）且退出即回收子进程，**严禁盲跑 GUI/`explorer.exe`/UAC 后声称已弹窗**。
- 需在真实桌面执行的 GUI 或常驻任务，请直接给出终端命令让用户执行；若用户本机已配置可选的自定义协议启动器（例如通过 `python -m acerola_orion install-launchers` 生成脚本至 `%USERPROFILE%\workspaces\launchers\` 并绑定 `agyrun://` 协议），可作为可选桌面穿透示例输出：
  - **静默示例**：`[点击执行：xxx](agyrun://xxx?silent)`（输出至 `launchers\_out\xxx.txt`）；
  - **窗口/UAC 示例**：`[点击执行：xxx](agyrun://xxx)`。

## 5. 时序抽检与 KV 缓存守护
- **按索引抽检**：查本地 SQLite/结构化日志优先按时间戳或 `mtime` 抽 2–3 组样本定性，非显式要求禁扫全盘。
- **守护 KV 缓存**：活跃长会话期间优先保持上下文前缀稳定，避免在后台无故终止或重启本地语言服务进程导致 Prompt KV 缓存失效。

## 6. 算力编排与 10 分钟熔断
- **单兵优先**：核心改造、SVG/UI 及 ≤5 文件耦合一律主智能体闭环；仅重度解耦支线才派 `invoke_subagent`。
- **主/子契约**：派活须写清**递增新路径（禁覆盖旧版）、接口契约与禁改边界**；`research`/`browser` 默认传 `Model: "flash"`，同步等待挂 `schedule(TimerCondition: "any", DurationSeconds: 90/180)`，超时即 `kill` 接手。子智能体禁套娃派生、缺上下文 ≤3 次查找后留桩上报。
- **防思考熔断**：预估超 3–5 分钟的推演或大文件生成须分步调工具重置计时，阶段成果立即落盘至项目源码、`docs/` 或 `.agents/checkpoints/`。
