# KV-KeepAlive（当前窗口上下文短时限次自动保活）

本技能配合 `Acerola-Orion` 的 `250s`（4分10秒）实测 KV 缓存安全线，使用会话内置的 `schedule` 单次链式定时器（`DurationSeconds=195` + `TimerCondition="any"`）在**当前窗口原上下文前缀**上自动唤醒续杯，不抢占桌面鼠标键盘焦点，且用户一旦回来发言即自动取消定时器（0 冗余损耗）。

## 1. 算力盈亏原则与次数护栏

- **心跳间隔固定 `195` 秒（3分15秒）**：卡在 `190s` 临期预警线后、`250s` 冷却断崖前 `55` 秒安全余量处。
- **默认续杯上限 `3` 次（总护航约 `14` 分钟）**：
  - `3 × 195s + 250s = 835s`（约 `13分55秒`）。
  - KV 缓存读取按 `0.1x` 计费（非免费），续杯 `1~3` 次仅消耗约 `10%~32%` 等效重算成本，净省 `68%~90%` 配额；超过 `8` 次（约 `30` 分钟）累计成本将反超冷启动全价重算。
- **参数换算与硬上限**：
  - 用户仅发 `保活` / `续杯`：`N = 3`。
  - 用户指定 `保活 K次`：`N = min(max(1, K), 6)`（若 `K > 6` 且未显式要求强制突破，自动钳制为 `6` 次并顺带提示超过 25 分钟自然放凉更省额度）。
  - 用户指定 `保活 M分钟`：按每轮延伸 `195s` 折算 `N = min(6, max(1, ceil((M * 60 - 200) / 195)))`（例如 `10分钟 -> 2次`、`15分钟 -> 4次`、`20分钟 -> 5次`）。

## 2. 执行规程（严格极简 Token 消耗）

### 场景 A：用户发起「保活」（开启第 `1/N` 轮倒计时）

1. 若用户消息中除了要求保活还包含正常业务问题，先简明回答该问题；若仅发 `保活`，直接进入下一步。
2. 立即调用 `schedule` 工具挂载第 `1/N` 轮单次定时器（**必须设置 `TimerCondition: "any"`，严禁使用 `CronExpression` 或 shell `sleep`**）：
   - `DurationSeconds`: `195`
   - `TimerCondition`: `"any"`
   - `Prompt`: `"[KV-KeepAlive 1/N] 自动保活唤醒：请保持极简思考（≤1句话），禁止读取文件或执行命令。若 1 < N，请立即调用 schedule(DurationSeconds=195, TimerCondition='any', Prompt='[KV-KeepAlive 2/N] ...') 挂载下一轮并仅输出单行状态；若已达 N/N 则不再挂载定时器，仅输出单行收尾提示。"`（将 `N` 替换为实际总次数）。
3. 向用户输出单行确认并**立即结束回合（不再调用其他工具）**：
   > `🛡️ 已开启短时 KV 保活（每 3分15秒 静默续杯，上限 N 次 ≈ 护航约 X 分钟；你随时直接发消息即自动终止保活）。`

### 场景 B：收到 `[KV-KeepAlive k/N]` 定时器唤醒通知

收到系统注入的 `[KV-KeepAlive k/N]` 通知时，**严禁发散思考、严禁调用任何文件/终端/检索工具**（避免 Output Token 膨胀）：

- **当 `k < N` 时**：
  直接调用一次 `schedule(DurationSeconds=195, TimerCondition="any", Prompt="[KV-KeepAlive {k+1}/{N}] ...")` 挂载下一跳，仅输出一行：
  > `🔥 KV 缓存已续杯 (k/N · 下次 3分15秒后，直接发消息即自动接管)`
  随后立即结束回合。

- **当 `k == N`（最后一轮）时**：
  **不再调用任何工具**，仅输出一行并结束回合：
  > `🔥 KV 缓存已续杯 (N/N · 已达预设保活上限，余温再护航 4分10秒 后自然休眠)`

### 场景 C：用户提前发言或要求「取消保活 / 停止保活」

- 若用户发来正常对话消息：`TimerCondition: "any"` 已自动提前销毁待触发定时器，直接正常响应用户问题即可，无需啰嗦保活状态。
- 若用户显式发送 `取消保活` / `停止保活`：调用 `manage_task(Action="list")` 检查是否有残余定时任务，若有则 `manage_task(Action="kill", TaskId=...)`，简短回复 `⏹️ 已关闭自动保活定时器。`
